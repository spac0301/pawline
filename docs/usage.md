# 표시되는 정보

## 입력 캐시

`입력 캐시 98.9%`는 최근 사용량 기록에서 전체 입력 토큰 중 캐시를 읽어 재사용한 비율입니다.
출력 캐시, 요청 성공률, 비용 절감률은 아닙니다. 옆의 시간은 기록의 나이이며 캐시 만료까지 남은 시간이 아닙니다.

Claude의 전체 입력은 일반 입력, 캐시 읽기, 캐시 쓰기를 합산합니다. 캐시 읽기만 적중으로 계산합니다.
사용량을 수집하지 못했으면 0%로 표시하지 않습니다. Pawline은 캐시를 유지하기 위한 요청을 보내지 않습니다.

## 모델

요청·설정 모델과 응답에서 관측한 모델 이름을 구분합니다. 응답 모델을 관측하지 못했으면 설정값으로 대신 채우지 않습니다.
관측된 이름은 서버가 보낸 정보이며 서버 내부의 실제 연산 구조를 증명하지는 않습니다.

## 작업 목록

현재 GPT 작업과 최근 완료한 작업은 5분간 표시합니다. Claude는 실행 중인 프로세스 또는 명시적으로 연결한 담당 역할을 표시합니다.
제목 생성·압축·하위 에이전트 활동은 별도 작업으로 나열하지 않습니다. 종료된 선택은 해제하며 원본 기록을 삭제하지 않습니다.

## 펫과 정보창

긴 제목이나 잘린 활동 상태에 마우스를 올리면 해당 부분만 펼쳐집니다. 정보창 크기와 다른 열의 위치는 바뀌지 않습니다. 정보창 메뉴에는 테마와 고정, 펫 메뉴에는 쓰다듬기·산책·종료가 있습니다.
펫의 일반 애니메이션과 작업 상태는 별개입니다. 진행 상태는 정보창의 글자를 확인하세요.
